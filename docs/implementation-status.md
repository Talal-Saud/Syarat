## العمل المتبقي

يبقى تنفيذ رفع الملفات المتوافق مع S3، الاستيراد من CSV، تدفق الـLeads الكامل وتغيير حالاتها، سجل التدقيق، التحليلات، واجهات العميل ولوحة المعرض ولوحة الإدارة كاملة، وربط مزود الرسائل، وتهيئة Redis/BullMQ التشغيلية. يجب تطبيق migrations على PostgreSQL قبل الاختبار التشغيلي الشامل.

## أوامر التحقق

```bash
pnpm install
pnpm --filter @syarat/database prisma:generate
pnpm typecheck
pnpm lint
pnpm --filter @syarat/api test
pnpm build
```
