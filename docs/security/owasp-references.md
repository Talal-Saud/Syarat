# OWASP references used for the security review

1. OWASP Top 10:2021 — Introduction: https://owasp.org/Top10/2021/A00_2021_Introduction/
2. OWASP API Security Top 10:2023 — Risk list: https://owasp.org/API-Security/editions/2023/en/0x11-t10/
3. OWASP Authentication Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html
4. OWASP REST Security Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/REST_Security_Cheat_Sheet.html
5. OWASP File Upload Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html

The review uses the official OWASP Top 10:2021 and API Security Top 10:2023 categories, with the Authentication, REST Security, and File Upload cheat sheets as control guidance.
